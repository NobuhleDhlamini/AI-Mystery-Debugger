# AI Mystery Debugger

An AI-powered programming debugger that identifies coding errors, explains their causes, and provides corrected solutions using Qwen2.5-Coder.

## Features

- Identify programming errors
- Explain the cause of errors
- Provide corrected code solutions
- Support multiple programming languages
- Simple and user-friendly interface
- AI-powered debugging

## Technologies Used

- HTML
- CSS
- JavaScript
- Qwen2.5-Coder
- Cloudflare Workers AI

## How It Works

1. Enter your code into the debugger.
2. Submit the code for analysis.
3. The AI identifies and explains the error.
4. Review the suggested corrected solution.
